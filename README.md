## Course Project - Getting and Cleaning Data

This repository contains my submission for the peer graded assignment
required for completing the course. The submission includes

- This readme file (README.md) describing the contents of the
  submission.
- A codebook (Codebook.md) describing the input data, the
  transformations performed and the output dataset.
- An R script (run_analysis.R) which performs the various steps
  described in the codebook.
- The output dataset (TidyData.txt).

The codebook contains information on the software used, the structure of
the data used as input, and describes the steps performed in producing
the final output. The results should be easily replicable using the R
script.

### Data Source

The data is sourced from the [Human Activity Recognition Using
Smartphones](http://archive.ics.uci.edu/ml/datasets/Human+Activity+Recognition+Using+Smartphones).
This study used commonly available smartphones to measure a set of
parameters related to the user’s motion while performing a range of
activities (walking, walking upstairs, walking downstairs, sitting,
standing, and laying down) using the pohne’s inbuilt accelerometer.

This project used the data purely for learning purposes. I acknowledge
that the dataset was used under the Creative Commons license and should
be cited as below.

Reyes-Ortiz, J., Anguita, D., Ghio, A., Oneto, L., & Parra, X. (2013).
Human Activity Recognition Using Smartphones \[Dataset\]. UCI Machine
Learning Repository. <https://doi.org/10.24432/C54S4K>.
